# Athletica

A browser stopwatch with laps, timing analytics, and keyboard shortcuts. Runs entirely in the browser — no install, no backend.

## Live

https://lemuelowusuansah.github.io/Athletica/

## Features

- Start / stop / reset with millisecond precision
- Lap timer with split and total times
- Keyboard shortcuts
- Session history
- Dark theme
- Mobile-friendly

## Controls

| Key | Action |
| --- | --- |
| Space | Start / stop |
| L | Record lap |
| R | Reset |

## Run locally

Open `index.html` in a browser. No install, no server.

Or serve it:

    python3 -m http.server 8000

Then open http://localhost:8000.

## Stack

Plain HTML, CSS, JavaScript. No build step.
